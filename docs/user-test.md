# Five-person test

**What we want to learn:** can someone who has never set up an agent understand what their agents are doing, see what it costs, and know when they're needed, without help?

**Who:** five people who use ChatGPT or Claude in a chat window but have never built an agent or written code. Mix of roles (a marketer, a founder, an ops person, a student, a freelancer). Not developers, not AI-twitter.

**Setup (before each session):** the app open on **Live** with the sample flow running in simulated mode, the timeline about half full. Fresh browser profile so the Live/Set up choice isn't remembered. Screen recording on, with permission.

**Length:** 20 minutes. Say: *"I'm testing the app, not you. Think out loud. There are no wrong answers."* Don't explain anything the app doesn't explain itself.

## Tasks

Read each task aloud. Don't help. If they're stuck for 60 seconds, note it and move on.

1. **First look (no task).** "Take a look at this screen. What do you think is going on?" *(Note the words they use for agents, the timeline and the orange.)*
2. **Who needs you.** "Is anything waiting for you? What would you do about it?"
3. **Cost.** "How much has this cost so far? Which agent is the most expensive?"
4. **What an agent is doing.** "What is the Researcher doing right now?" *(Do they find the hover?)*
5. **Change a step.** "Go to where the flow is set up. Make the Writer's instructions say 'keep it under 100 words'." *(Do they find ••• → prompt?)*
6. **Make two things happen at once.** "Make 'Customer quotes' happen at the same time as 'Competitor pricing'." *(Drag on the canvas.)*
7. **Trust.** "You'd like the Reviewer to stop asking you every time once it's proven itself. How would you set that up?" Then: "What do you think 'Ask until it's earned it' means?"
8. **Run it.** "Run the flow and approve whatever it asks."

## After the tasks (5 minutes)

- "In one sentence, what is this for?"
- "Would you use this instead of doing the work in a chat window? For what?"
- "What would you expect to pay for it, if anything? Would you rather download it or use it in a browser?"
- "What confused you most?"

## What counts as a pass

- At least 4 of 5 find the waiting item and read the cost without help.
- At least 3 of 5 explain "Ask until it's earned it" in their own words.
- At least 3 of 5 name a real task of their own they'd run through it.

If the first two fail, the Live view needs work before anything else. If the third fails, the idea needs a sharper use case before it needs more features.
