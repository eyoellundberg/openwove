# Security

OpenWove runs on your computer, keeps your API keys in the Keychain (or `.env.local` when run from source), and lets agents touch only the `workspace/` folder. If you find a way around any of that, or any other vulnerability, please tell us privately first.

**Report it** through GitHub's private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. Please include what you did, what happened, and which release you downloaded or which commit you built.

We'll reply as soon as we can, and credit you in the fix if you'd like.

The beta is not signed with an Apple developer certificate yet. That's a known limit, not a vulnerability.
